# Assessment Answers

### 1. B — `ip addr`

Displays network interfaces and assigned IP addresses.

---

### 2. B — Determine how packets reach their destination

The routing table tells Linux which path to use when sending traffic.

---

### 3. C — `curl`

`curl` verifies communication with an application using protocols such as HTTP or HTTPS.

---

### 4. C — ICMP

`ping` sends ICMP Echo Requests to test basic network reachability.

---

### 5. B — Listening network sockets

`ss -tuln` identifies services that are waiting for incoming connections.

---

### 6. B — Query DNS records

`dig` verifies that DNS can resolve hostnames into IP addresses.

---

### 7. C — A successful DNS lookup only proves name resolution

DNS translates names into IP addresses. It does not guarantee successful communication.

---

### 8. B — Application Layer

An HTTP 200 response demonstrates successful communication with the web application.
